# API Reference

## `new Database(configuration)`
| Option | Type | Description |
| --- | --- | --- |
| `context` | `DbContext` | Context generated by `acryps-local create-context` |
| `local` | `DatabaseConnection` | Database at the current location, connected all the time |
| `remotes` | `DatabaseConnection[]` | Databases at other locations, connected on demand |
| `runContext` | `RunContext` | Passed to every context |
| `remoteIdleTimeout` | `number` | Milliseconds a remote connection stays open after its last use, default `60000` |

### `DatabaseConnection`
| Option | Type | Description |
| --- | --- | --- |
| `tag` | `string` | Unique name of the database, stored in pointer targets |
| `host` | `string` | Hostname or IP address |
| `database` | `string` | Database name |
| `user` | `string` | User |
| `password` | `string` | Password |
| `min` | `number` | Minimum pooled connections, default `1` |
| `max` | `number` | Maximum pooled connections, default `8` |
| `options` | `object` | Further postgrejs options (port, timeouts, ...) |

Tags must be unique across `local` and `remotes`.

## Properties
| Property | Description |
| --- | --- |
| `tag` | Tag of the local database |
| `sets` | Sets of the context, see [Sets](cohorts.md#sets) |
| `views` | Views of the context, reading the local database |

## Methods
| Method | Description |
| --- | --- |
| `connect()` | Connects to the local database |
| `close()` | Closes all connections |
| `create(item, comment?)` / `create(pointerId, item, comment?)` | [Create](writing.md#create) |
| `update(item, comment?)` / `update(pointerId, item, comment?)` | [Update](writing.md#update) |
| `delete(item, comment?)` / `delete(pointerId, item, comment?)` | [Delete](writing.md#delete) |
| `move(item, target)` | [Move](writing.md#move) a cohort to the database tagged `target` |
| `fetch(reference)` | [Load](querying.md#loading-entities) a referenced entity |
| `related(reference)` | [Query](querying.md#loading-entities) the entities referencing the item |
| `backload(item, tree, pointerId?)` | Loads missing referenced data, see [Includes](querying.md#includes) |
| `createDuplicate(item)` | Duplicates the item, like vlquery |

## Set methods
| Set | Methods |
| --- | --- |
| Root sets | `find(id)`, query methods, `first/single/toArray/count` + `Local/Remote/All` |
| Member sets | `find(pointerId, id)`, query methods, `first`, `single`, `toArray`, `count` |
| Other sets, views | `find(id)`, query methods, `first`, `single`, `toArray`, `count` |

Query methods: `toQuery`, `where`, `include`, `includeTree`, `orderByAscending`, `orderByDescending`, `skip`, `limit`, `page`.
